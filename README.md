# Brick Breaker Game

A portrait mobile brick-breaker game built with HTML, CSS and JavaScript. Position the launcher, plan a bank shot and build an increasingly chaotic arsenal of balls before the advancing bricks reach the danger line.

## Play locally

The prototype has no build step or dependencies. Open `index.html` directly, or serve the folder locally:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Controls

- Drag along the bottom of the board to reposition the launcher.
- Drag anywhere above the launcher to aim.
- Release to fire the full volley.
- Collect `+1` orbs to add a ball to future volleys in the current run.

## Test Mode

Tap the version label five times to choose a starting round and ball count, then restart immediately with those test values.
