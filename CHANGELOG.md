# Changelog

All notable changes to the project will be documented in this file.

## [0.1.0] - 2026-09-17

### Added

- Portrait-first browser game shell and neon geometric visual direction.
- Horizontal launcher movement and drag-to-aim controls.
- Wall-bounce trajectory guide.
- Sequential multi-ball volleys with stable sub-stepped collision physics.
- Numbered bricks that take one damage per collision.
- Procedural brick rows with intentional gaps.
- Bricks descending one row after every completed volley.
- Permanent `+1 Ball` pickups for the current run.
- Danger line, game-over state and restart flow.
- Round and ball-count HUD.
- Hidden Test Mode opened by tapping the version label five times.
